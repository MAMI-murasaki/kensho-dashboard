# 懸賞応募ダッシュボード

応募した懸賞の記録と当落を、スマホでひと目で確認するためのページです。
GitHub Pages で公開され、毎晩 20:00 の自動応募のあとに `data.json` が更新されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ本体（見出し・サマリー・フィルタ・一覧の入れ物） |
| `styles.css` | ライラック／パープル基調のスタイル（スマホ縦画面優先） |
| `app.js` | `data.json` を読み込み、サマリー・絞り込み・一覧を描画 |
| `data.json` | 応募データ（**日々の更新はこのファイルだけ**） |
| `manifest.json` / `icon.svg` | スマホのホーム画面に追加するときのアイコン設定 |

## データの形

```json
{
  "site_title": "懸賞応募ダッシュボード",
  "updated_at": "2026-11-14 21:00",
  "next_run": "毎日 20:00",
  "items": [
    {
      "id": "2026-11-14-01",
      "date": "2026-11-14",
      "organizer": "主催・企画名",
      "prize": "賞品名",
      "slots": "3名",
      "category": "家電・生活",
      "deadline": "2026-12-13 23:59",
      "result_date": null,
      "result_note": null,
      "status": "当落待ち",
      "url": "https://example.com/"
    }
  ]
}
```

- `category` は「テーマパーク・鑑賞」「家電・生活」「食品・お酒」「その他」のいずれか。
- `deadline` / `result_date` は `YYYY-MM-DD HH:MM` 形式、分からなければ `null`。
- `status` は「当落待ち」「当選」「落選」「発送待ち」など。表示色は自動で変わります。
- `url` は公開されている公式キャンペーン記事の URL のみ。

## 日々の更新

1. `data.json` の `items` に応募したものを追記（`id` は `応募日-連番`）
2. `updated_at` をその日の日付に変更
3. コミットして `main` にプッシュ

ページ側は `data.json` を読むだけなので、HTML や CSS を触る必要はありません。

## 方針

- 氏名・住所・電話番号・メールアドレス・会員 ID・パスワードなどの個人情報は一切載せません。
- 載せるのは「応募日・主催・賞品名・カテゴリ・締切／当落予定・ステータス・公開記事 URL」だけです。
