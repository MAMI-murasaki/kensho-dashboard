# 懸賞応募ダッシュボード

応募した懸賞の記録と当落を、スマホでひと目で確認するためのページです。
GitHub Pages で公開され、毎晩 20:00 の自動応募のあとに `data.json` が更新されます。

## 画面の構成（2026-11-20 改修）

- **もうすぐ結果・お届け予定**: 発表日や発送時期が分かっているものを近い順に最大5件（「あと○日」「今日発表！」など）。それ以上はリストで確認。
- **おめでとう**: 「当選」「発送済み」のものが1件でもあると、上部に金色のお祝い表示が出ます。
- **並び替え**: 「応募が新しい順」（既定）と「結果・お届けが近い順」をワンタップで切り替え（選んだ並びは端末に記憶）。
- **カード**: `🎯 12/1(火) 発表予定（あと11日）` `📦 2026年12月下旬 発送予定` を目立たせ、締切は控えめなメタ情報として残しています。
- **カテゴリ**: データにあるカテゴリから自動でチップを作ります（件数付き）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ本体（見出し・サマリー・フィルタ・一覧の入れ物） |
| `styles.css` | ライラック／パープル基調のスタイル（スマホ縦画面優先） |
| `app.js` | `data.json` を読み込み、サマリー・絞り込み・並び替え・一覧を描画 |
| `data.json` | 応募データ（**日々の更新はこのファイルだけ**） |
| `manifest.json` / `icon.svg` | スマホのホーム画面に追加するときのアイコン設定 |

`index.html` の `styles.css?v=…` / `app.js?v=…` は、CSS や JS を変えたときに更新してください（スマホのキャッシュ対策）。

## データの形

```json
{
  "site_title": "懸賞応募ダッシュボード",
  "updated_at": "2026-11-20 21:55",
  "next_run": "毎日 20:00",
  "items": [
    {
      "id": "2026-11-20-04",
      "date": "2026-11-20",
      "organizer": "主催・企画名",
      "prize": "賞品名",
      "slots": "300名",
      "category": "食品・お酒",
      "deadline": "2026-11-24",
      "result_date": "2026-12-01",
      "result_label": "抽選",
      "result_approx": false,
      "ship_label": "2026年12月上旬",
      "result_note": "12月1日に抽選・当選者のみ発送（都道府県とイニシャルをHP掲載）",
      "status": "当落待ち",
      "url": "https://example.com/"
    }
  ]
}
```

- `category` は「テーマパーク・鑑賞」「家電・生活」「食品・お酒」「美容・日用品」「生活雑貨」「旅行・宿泊」「ギフト券・その他」「その他」など（画面のチップはデータから自動生成）。
- `date`（応募日）/ `deadline` / `result_date` は `YYYY-MM-DD HH:MM` 形式、分からなければ `null`。
- `result_date` は**当落（抽選）が分かる日**。`result_label` に「抽選」などを入れると `🎯 12/1 抽選予定` と表示します（省略時は「発表」）。
- `result_approx: true` は「12/15以降」のような幅のある予定。`🎯 12/15(火)以降` と表示します。
- `ship_label` は**発送予定時期**（「2026年12月下旬」「2027年1月中旬頃」「2026年12月〜2027年1月頃」など）。分かっているものだけ入れてください。並び順のために月・上旬/中旬/下旬からおおよその日付を内部で推定しますが、表示はラベルのままです。
- `result_note` は当選連絡のしかた。`発送をもって` / `当選者のみ発送` / `メールで連絡` / `XのDMで連絡` などを、画面側が「📮 賞品の発送をもって当選発表」「✉️ 当選者のみメールで連絡（落選通知なし）」のような短い言葉に置き換えます（当てはまらない文はそのまま表示）。
- `status` は「当落待ち」「当選」「落選」「発送待ち」「発送済み」など。`当選`・`発送済み` は上部のお祝い表示にも出ます。
- `url` は公開されている公式キャンペーン記事の URL のみ。

## 日々の更新

1. `data.json` の `items` に応募したものを追記（`id` は `応募日-連番`）
2. 分かっている `result_date` / `ship_label` を忘れずに入れる（応募時に公表されていれば必ず）
3. `updated_at` を更新
4. コミットして `main` にプッシュ

ページ側は `data.json` を読むだけなので、HTML や CSS を触る必要はありません。

## 方針

- 氏名・住所・電話番号・メールアドレス・会員 ID・パスワードなどの個人情報は一切載せません。
- 載せるのは「応募日・主催・賞品名・カテゴリ・締切／当落予定・発送予定時期・ステータス・公開記事 URL」だけです。
